# Sicherheitslücken melden

Bitte nicht als öffentliches Issue, sondern über **Security → Report a
vulnerability** in diesem Repository (private Meldung an den Maintainer).

Gemeint sind Fehler in der Software, etwa ein Weg, über die HTTP-Schnittstelle
Daten zu verändern oder Dateien außerhalb des Dashboards zu lesen. Dass die
Schnittstelle ohne Anmeldung lesbar ist, ist bekannt und im README unter
„HTTP-Schnittstelle: nur lesend, ohne Anmeldung“ beschrieben.

Fragen zur Elektroinstallation gehören zu einer Elektrofachkraft, nicht in
eine Sicherheitsmeldung.
